# Smart Parking Management System 🚗

## About the Project
Smart Parking Management is a team-developed mobile application that helps users select parking slots and manage parking bookings conveniently. The application provides separate functionalities for users and administrators.

## Features
- User Registration and Login
- Parking Slot Selection
- Parking Booking Management
- User and Admin Functionalities
- Firebase Integration

## Tech Stack
- **Frontend:** React Native, JavaScript
- **Backend / Database:** Firebase
